Analyzers

        
Eight specialists on every build.

      

      
Each analyzer runs with its own expert system prompt and returns a 1–10 score plus findings with a severity, the file and line, and a concrete fix. Turn any of them off globally in Manage Jenkins.

    

    

      

        

        
AI Code Review
code-review
        
Correctness, performance, readability, SOLID and DRY violations, error handling, naming and anti-patterns.

        
Reads Source files

      

      

        

        
Vulnerability Analysis
vulnerability
        
OWASP Top 10, hardcoded secrets, injection, path traversal, weak crypto, SSRF and unsafe deserialization, each mapped to a CWE ID.

        
Reads Source files

      

      

        

        
Architecture Drift
architecture-drift
        
Works out your intended architecture, then flags layer violations, circular dependencies, god classes and leaking API boundaries.

        
Reads Source files

      

      

        

        
Test Gap Analysis
test-gaps
        
Finds untested paths, missing boundary and error-case tests, and tests that assert nothing, then describes the tests to add.

        
Reads Source files

      

      

        

        
Dependency Risk
dependency-risk
        
Unpinned versions, copyleft license conflicts, unmaintained packages, duplicate libraries and deep transitive trees.

        
Reads Manifests

      

      

        

        
Commit Intelligence
commit-intel
        
Rates commit message quality and change cohesion, and catches breaking changes that nobody announced.

        
Reads Git history

      

      

        

        
Pipeline Advisor
pipeline-advisor
        
Reviews your Jenkinsfile for stages that could run in parallel, missing caches, absent timeouts and retries, and unsafe secret handling.

        
Reads Jenkinsfile

      

      

        

        
Release Readiness
release-readiness
        
Weighs every other result, security 3× and architecture 2×, into a release verdict and names the issues that should block it.

        
Reads All prior results

      

    

  







  

    

      

        
Quality gate

        
Ship on a score. Fail when the analysis fails.

      

      
Set a threshold, drag the scores, then break something. The result and the log lines follow the same rules as the forgeAI step.

Pipeline syntax

        
One step, or one analyzer at a time.

      

      
forgeAI runs the full suite on your workspace. forgeAIScan runs a single analyzer on any text you hand it. Both return values your pipeline can branch on.

    

    

      

        

          
          
          
          
        


stage('ForgeAI') {
  steps {
    script {
      def report = forgeAI(
        analyzers: ['code-review', 'vulnerability', 'architecture-drift',
                    'test-gaps', 'dependency-risk', 'commit-intel',
                    'pipeline-advisor', 'release-readiness'],
        sourceGlob: 'src/main/java/**/*.java',
        contextInfo: 'Spring Boot service, hexagonal architecture',
        failOnCritical: true,
        criticalThreshold: 6
      )
      echo "Composite: ${report.compositeScore}/10"
      echo "Security:  ${report.vulnerabilityScore}/10"
    }
  }
  post {
    always {
      archiveArtifacts artifacts: 'forgeai-reports/**', allowEmptyArchive: true
    }
  }
}


script {
  def sec = forgeAIScan(
    analyzer: 'vulnerability',
    source: readFile('src/main/java/com/acme/pay/OrderRepository.java'),
    context: 'Java 17 REST API that stores card holder data'
  )
  echo "Security ${sec.score}/10 (${sec.severity}): ${sec.summary}"
  if (sec.criticalCount > 0) {
    unstable("${sec.criticalCount} critical vulnerabilities")
  }
}


// Manage Jenkins → System → ForgeAI Pipeline Intelligence
//   Provider: Ollama (Local)
//   Endpoint: http://ollama.internal:11434   (reachable from the controller)
//   Model:    codellama:13b
pipeline {
  agent any
  stages {
    stage('ForgeAI') {
      steps {
        script {
          def r = forgeAI(analyzers: ['code-review', 'vulnerability', 'test-gaps'],
                          sourceGlob: 'src/**/*.py',
                          contextInfo: 'FastAPI service, air-gapped network')
          echo "Composite: ${r.compositeScore}/10"
        }
      }
    }
  }
}

Get started

      
Running in three steps.

    

    
    
      
  1. 
        
    Install the plugin
    
        
    In Manage Jenkins → Plugins → Available plugins, search for ForgeAI Pipeline Intelligence and install it. Needs Jenkins 2.528.3 or newer.
    
      
    2. 
      
  2. 
        
    Connect a model
    
        
    Open Manage Jenkins → System → ForgeAI Pipeline Intelligence. Pick a provider, choose the Secret Text credential with your API key, and click Test Connection.
    
      
    3. 
      
  3. 
        
    Add the step
    
        
    Call forgeAI in any stage that has a workspace. The report lands in forgeai-reports/.
    

    forgeAI analyzers: ['code-review', 'vulnerability']
    
      
    4.
